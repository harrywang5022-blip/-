# 🧻 🎬 安屎之亂：衛生紙價格策略賽局 (Toilet Paper Price War)
> 專為國高中公民與社會科設計・寡占市場、卡特爾協議與囚徒困境即時連線教學遊戲

## 📖 遊戲背景（真實歷史事件）
**2018 年 2 月至 3 月**，台灣爆發震驚全台的「衛生紙之亂」（俗稱「安屎之亂」）。因賣場公關行銷失當與媒體渲染「衛生紙即將大漲 10%～30%」，造成全台民眾恐慌性排隊搶購、全台賣場衛生紙被掃空。
隨後，**行政院公平交易委員會**介入調查，認定業者散布不實訊息誤導消費者、破壞市場交易秩序，依《公平交易法》重罰 **新台幣 350 萬元**。

本賽局將學生帶回 2018 年風暴現場，各組化身為各大造紙廠商（舒潔、五月花、春風、蒲公英等），體驗寡占市場中的定價博弈！

## 🎮 遊戲規則精簡版

### 1. 消費者原則
- **只選全場最低價購買**。衛生紙品質皆獲肯定，消費者極度價格敏感。
- 開高價者哪怕只差 50 元，本回合**銷量直接為 0 箱**！

### 2. 每回合報價選項（三選一）
- **450 元**（高利潤・協商合作價）：單箱毛利 +$300（全員合作時總利潤最高，消費者最慘）。
- **400 元**（搶單價・微幅偷跑背叛）：單箱毛利 +$250（略低於 450 元，企圖低調獨吞全場訂單）。
- **200 元**（破盤價・割喉價格戰）：單箱毛利 +$50（保本底價，消費者最大贏家，廠商做白工）。

### 3. 遊戲階段設計
- **第 1–2 回合（獨立決策）**：🚫 廠商嚴禁跨組溝通，秘密報價。體驗資訊不對稱與囚徒困境猜忌。
- **第 3–4 回合（開放協商）**：💬 廠商可面對面走動談判，訂定「全體協議價」。但在秘密出價時，考驗是守約還是背叛！
- **第 5 階段（反思論壇）**：全班投影「小組討論與紀錄單」，深入《公平交易法》第14條（禁止聯合行為）與消費者權益。

### 4. 勝負與市場分配
- 市場每回合總需求：**1,200 箱**（每箱生產成本 150 元）。
- **價格不同**：全場開出最低價的廠商**獨得所有 1,200 箱訂單**，其餘廠商銷量為 0。
- **價格相同**：由所有開出最低價的廠商**平分 1,200 箱訂單**。

### 二、核心討論與反思
1. **不能溝通時（R1-R2）**：我們不敢開高價（450元）的主要顧慮是什麼？
2. **開放溝通後（R3-R4）**：各組有遵守協議嗎？若有人背叛（偷偷降價），動機是什麼？
3. **甚麼情況生產者受益最大？**
4. **甚麼情況消費者受益最大？**
5. **政府要如何保障消費者受益最大？**（探討《公平交易法》聯合行為禁止、消保官查價與平抑物價）

## 🚀 部署與本機執行指南

本專案採用 **React 19 + TypeScript + Vite + Tailwind CSS + Node.js (Express & WebSockets)** 全端架構。

### 本機開發與執行
```bash
# 1. 安裝套件
npm install

# 2. 啟動伺服器 (包含 WebSocket 與 Vite 前端，監聽 3000 埠)
npm run dev

# 3. 建置生產環境
npm run build
```

### 推薦一鍵免費部署平台（免 Google 登入、永久公開網址）
若想在教學時讓全班學生自由掃碼，不受 Google 帳號身分驗證限制，可將此 GitHub 專案部署至以下平台：
1. **Zeabur**（推薦，台灣連線極速，支援 WebSocket）：直接 Import GitHub Repo 即可一鍵部署。
2. **Render.com**：選擇 Web Service，Build Command 為 `npm run build`，Start Command 為 `node server.ts`。
3. **Railway.app**：支援 Node.js + WebSocket 自動偵測。
